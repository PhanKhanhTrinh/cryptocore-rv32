# Documentation Assets

This directory contains project-specific figures selected for the public repository:

- `diagrams/`: system architecture and firmware control flow.
- `waveforms/`: representative Vivado/XSim verification captures.
- `implementation/`: Vivado device, utilization, timing, and power captures.
- `results/`: plots generated from the thesis measurements.
- `board/`: PYNQ-Z2 demonstration photos for the two LED display modes.

Working drafts, administrative forms, signatures, duplicated exports, and third-party theoretical illustrations are intentionally excluded.
